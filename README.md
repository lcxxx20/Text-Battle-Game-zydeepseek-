# 文字格斗 · Java Swing 版

这是原控制台版《文字格斗》的独立 Java 图形界面版本，目录名为 `javawzgdyx`。

- 原项目：`D:\javatext\lianxi\src\wenzigedouyouxi`
- 本项目：`C:\Users\lcx\Desktop\javawzgdyx`

原项目代码、类名和文件均未改动。本项目是一套全新的 Swing 实现，只复用原版的游戏规则与数值。

---

## 一、运行

### 环境要求

- Windows 10 / 11
- JDK 17 或更高版本（原版使用了 JDK 17 的 `Random.nextInt(origin, bound)`）

确认环境：

```bat
java -version
javac -version
```

### 启动方式

**最简单：双击 `启动游戏.bat`。**

脚本会自动处理：

1. 如果检测到 `javac`，先重新编译到 `out`；
2. 优先用 `javaw` 启动，不显示控制台窗口；
3. 如果本机没有 JDK，但 `out` 中有预编译文件，也会尝试用已有的 Java 运行。

也可以先双击 `编译.bat`，再双击 `启动游戏.bat`。

### 手动编译与运行

在项目根目录打开命令行：

```bat
javac -encoding UTF-8 -d out -sourcepath src src\javawzgdyx\Main.java
java -cp out javawzgdyx.Main
```

### 窗口

- 默认大小：1240 × 860
- 最小大小：1080 × 760
- 支持自由拉伸；两档尺寸均做过布局渲染检查

## 二、玩法

### 模式 01：狂扁 deepseek

单人挑战随机生成的杂鱼敌人 `deepseek`。

- 玩家每次选择一个职业技能。
- `deepseek` 没有技能，只会基础攻击（0~39 点伤害）。
- 回合顺序与原版一致：

```text
玩家行动
  → 敌人死亡？胜利
  → 玩家回合数 ≤ 0？失败
  → 敌人行动
  → 玩家死亡？失败
  → 下一回合
```

- 初始回合数 20。
- 兔子的怀表会让回合数净 +1：先 `+2`，再按一次技能行动 `-1`。

### 模式 02：双人对打

两名玩家在同一台电脑上创建角色并轮流出手。

- 每个行动轮自由选择「由谁出手」，再由出手者选择技能。
- 防守方倒下时结束，出手方获胜。
- **没有回合耗尽判定**：回合数仍显示并扣减，但不会因为回合数归零而失败或结束。这是原版的规则。
- 没有机械的先后手限制，双方可以连续让同一个角色出手。

### 通用规则

- 初始生命：`100 + nextInt(0, 100)`，即 **100~199**。
- 生命上限等于初始生命。
- 初始回合：20。
- 玩家每次使用技能消耗 1 回合。
- 伤害为负数时，会给对方回血，且**不受生命上限限制**。
- 食油饼的回血为 5~14，但**不能超过自己的生命上限**；界面日志显示实际回复量。
- 复活：每局只能使用一次，生命值完全回满，使用后从技能栏移除。

### 操作

- 鼠标点击卡片与按钮。
- `Tab` 切换焦点，`Enter` / `空格` 触发当前按钮。
- 战斗中按 `Esc`，或点击「退出本局」，返回主菜单。
- 结算界面提供「再战一局」和「返回主菜单」。
- 姓名：不能为空，不能包含空格或其他空白字符，最多 12 个字符。
  - 原控制台用 `Scanner.next()` 读取姓名，因此原版本来就不能输入空格；12 字限制是图形界面的排版限制。

## 三、职业与技能

### 不死者

| 技能 | 类型 | 效果 |
| --- | --- | --- |
| 兔子的怀表 | 辅助 | 本回合不造成伤害；回合数 +2 后再扣 1，净 +1 |
| 黑之力 | 爆发 | 造成 0~49 点伤害 |
| 大工的长锚 | 重击 | 稳定造成 20~29 点伤害 |
| 复活 | 禁忌 | 生命值完全回满；每局只能使用一次，用后移除 |

### 家成

| 技能 | 类型 | 效果                     |
| --- | --- |------------------------|
| 脱裤子放屁 | 混沌 | 造成 -40~69 点伤害；负数会给敌人回血 |
| 食油饼 | 回复 | 回复 5~14 点生命值，不超过生命上限   |
| 内卷 | 重击 | 造成 40~54 点伤害           |
| 大狗叫 | 混沌 | 造成 -20~59 点伤害；负数会给敌人回血 |

### deepseek（不可选）

- 职业：杂鱼
- 性别：男 / 女随机
- 生命：100~199
- 基础攻击：0~39
- 没有技能，也没有实际生效的回合限制

## 四、项目结构

```text
javawzgdyx/
├─ 启动游戏.bat              # 编译（可选）并启动游戏
├─ 编译.bat                  # 仅编译
├─ README.md                 # 本文件
├─ ARCHITECTURE.md           # 架构与实现说明
├─ src/
│  └─ javawzgdyx/
│     ├─ Main.java           # 程序入口
│     ├─ model/              # 角色、技能、数值规则
│     ├─ game/               # 对战流程控制器与界面契约
│     └─ ui/                 # Swing 窗口、页面、主题
│        └─ components/      # 自绘按钮、卡片、日志、结算遮罩等
└─ out/                      # 编译后的 .class 文件
```

### 三层职责

- **model**：只负责规则和数值，不依赖 Swing。
- **game**：组织回合流程、计时和胜负判定；通过 `BattleView` 接口驱动界面。
- **ui**：Swing 页面、自定义绘制、动画和日志展示。

依赖方向：

```text
ui  ──►  game  ──►  model
```

`game` 不依赖具体的 Swing 页面，因此战斗流程可以用测试用的假界面独立验证。

## 五、与原始控制台版的关系

原目录 `D:\javatext\lianxi\src\wenzigedouyouxi` **未被修改**。

本项目保留原版的所有关键数值和特殊规则，包括：

- 初始生命 100~199、生命上限、初始 20 回合；
- 基础攻击 0~39；
- 各技能的确切随机区间（例如 `nextInt(-50, 50)` 的上限不含 50）；
- 负伤害给敌人回血，且不回退到生命上限；
- 食油饼封顶回血；
- 复活只生效一次；
- 模式 02 没有回合耗尽判定。

不同于原版的地方主要集中在表现层：

- 控制台文本 → Swing 日志面板与技能卡；
- `Scanner` 输入 → 鼠标/键盘界面；
- 新增页面切换、选角卡、生命条动画、伤害飘字、结算遮罩；
- 日志增加了与技能效果对应的气氛描述，但结算数值忠实于原版。

更详细的类映射和流程说明见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 七、常见问题

**双击 `启动游戏.bat` 后没有反应**

1. 在命令行运行 `java -version`，确认版本不低于 17；
2. 确认 `javac` 可用；如果不可用，确认 `out` 目录存在；
3. 如果程序启动后立即退出且无提示，请改用 `java -cp out javawzgdyx.Main` 运行，这样可以看到异常信息。

**提示找不到 `javac`**

安装 JDK 17 或更高版本，并把 JDK 的 `bin` 目录加入系统 `PATH`。只安装 JRE 不能编译；如果项目自带 `out` 预编译文件，可以尝试直接运行 `启动游戏.bat`。

**中文显示成方框**

本项目使用 Windows 自带的「微软雅黑」和「楷体」。请确认系统中有这两个字体；中文版 Windows 默认具备。

**窗口太小**

最小尺寸为 1080×760；如果屏幕分辨率低于这个值，请调高显示分辨率或缩放比例。
